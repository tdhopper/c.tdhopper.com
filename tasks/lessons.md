# Lessons

- When Tim's request is a direct match for an available named service skill, check that skill and its credential path before choosing a local fallback. For podcast transcription, prefer the AssemblyAI skill when diarized speaker labels materially improve the site transcript.
- A transcript is not finished when diarization succeeds. Preserve each speaker's characteristic phrasing and humor, but remove obvious ASR errors, empty fillers, accidental word repetitions, and formatting that makes long turns hard to read.
